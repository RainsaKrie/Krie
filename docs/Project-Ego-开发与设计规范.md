# 📖 Project Ego: 开发与设计规范 (Design Spec)

## 🔮 核心设计哲学

“精密的设计图纸，未经渲染的物理本质”

去除一切试图模拟光源的阴影（Drop Shadow）和渐变，只保留纯白、纯黑、以及代表坐标参考的单像素网格。将大模型那种野蛮、不可控的内容，锁死在几何体结构中。

## 1. 颜色与材质 (Color & Texture) —— 绝对降噪

### Ego White (底色)

`#FFFFFF`

纯白。大面积留白，形成强烈的“画廊/展览馆”的空间感与克制感。

### Grid Line (网格虚线)

`rgba(0, 0, 0, 0.08)`

黑色 `8%` 透明度。作为参考线，切割屏幕逻辑区。

### Active Border (动作线)

`#111111`

极深的黑色。只有在用户悬停或选中时，才用 `1px` 细线框出边界。

### Base Text (主文本)

`#111111`

纯黑或极深黑，绝对不使用灰色作为正文，保证高对比度与易读性。

### Muted Text (辅助文本)

`#767676`

中灰色。只用于代码行号、时间戳等边缘信息。

### Warning/Energy (警示红)

`#FF3333`

纯正的警告红。整个应用中唯一的彩色。只用于状态灯、高亮引用或错误提示。不允许大面积涂抹。

### Paper Noise (纸张肌理 - 核心要素)

在前端的 CSS 根部，使用 SVG 引入高密度的无序噪点，降低透明度，覆盖全屏。

作用：

让纯白不是反光的塑料白，而是呈现出一种“高档粗糙卡纸、或者未涂布印刷纸”的物理纤维感。

## 2. 几何与布局规则 (Geometry & Layout) —— 0 圆角

### 直角法则 (90-Degree Orthogonal)

`border-radius: 0px`

全局禁用所有 rounded 类。

无论是输入框、卡片、模态弹窗还是按钮，必须是绝对锋利的直角。

### 不对称网格 (Asymmetric Grid)

不采用平衡、等宽的多栏布局。

左侧可以用 `15%` 的极窄距离画一根贯穿屏幕的垂线，用来放导航和状态栏；右侧大面积空间用来展示内容（就像 architectural drawing 建筑工程图纸）。

### 十字准星定位 (Crosshair Alignment)

在所有的水平线和垂直线的交叉点上，显式地打上 `[+]` 符号，作为视觉定位锚点。

## 3. 排版体系 (Typography) —— 极端的物理张力

### Title (解构大标题)

使用高饱和度的粗衬线体 (`Font-Serif`)。

大字号（如 `6xl` 或 `7xl`），字母间距极其紧凑（`Tracking-tighter`），甚至可以做 `1-2px` 的字符向上/向下偏移（Offset），营造一种“活字印刷由于机械偏差产生错位”的手工感与反叛感。

### Data / Copy (正文与数据)

使用强规则的等宽字体 (`Monospace`)，如 `JetBrains Mono`。

字号偏小，字重偏细，每一行都要有清晰的行高，保证在纯白纸底上像一排排规整的代码。

## 4. 纯白 ToB 基建特化交互 (UX Flow)

### 无阴影卡片流 (No-Shadow Cards)

卡片之间不通过“投影浮起”来凸显，而是紧密拼接在一起，只共享一根 `1px` 的 `rgba(0,0,0,0.08)` 边框线。

### 状态的硬切换 (Hard-State Toggle)

Checkbox 选中时不使用软弹的动画。选中是 `[X]`，未选中是 `[ ]`。

### 输入框的强聚焦 (Input Focus)

输入框平时无边框，仅有一根下划线。

一旦聚焦（Focus），不产生柔和的蓝色光晕，而是直接将四边框变为 `1px` 的纯黑色实线，并伴随一个闪烁的光标。
